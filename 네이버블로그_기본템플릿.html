🧩 이 파일은 뭔가요?

매 글마다 똑같이 반복해서 만드는 서식(요약박스 · 표 · 주의박스 · 사진자리 · 출처박스)만 뽑아둔 골격 파일입니다. 네이버 스마트에디터에 딱 한 번만 등록해두면, 다음 글부터는 템플릿을 불러와서 내용만 채우면 됩니다.

1️⃣ 최초 1회 — 내 템플릿으로 등록하기

  1. 아래 「▼ 여기부터 복사 ▼」 ~ 「▲ 여기까지 복사 ▲」 구간을 드래그해서 복사
  2. 네이버 블로그 → 글쓰기 → 본문에 붙여넣기
  3. 서식이 깨진 곳이 없는지 한 번 훑어보기 (특히 표와 색 박스)
  4. 에디터 우측 상단 템플릿 → 내 템플릿 → 현재 글 추가
  5. 이름을 기본골격 등으로 저장 → 그대로 창 닫기 (발행하지 않음)

2️⃣ 매번 — 글 쓸 때

  1. 글쓰기 → 템플릿 → 내 템플릿 → 기본골격 불러오기
  2. 【빨간 글씨 자리】만 실제 내용으로 교체
  3. 안 쓰는 블록은 통째로 삭제, 더 필요한 블록은 아래 블록 라이브러리에서 복사해 삽입

⚠️ 등록 전에 확인할 것

  • 에디터 버전에 따라 색 배경 박스가 회색으로 변하거나 테두리가 빠질 수 있습니다. 등록 직후 임시저장 → 미리보기로 한 번 확인하세요.
  • 박스 서식이 안 살아남으면, 해당 블록은 에디터 기본 기능(인용구 · 구분선)으로 대체하는 편이 안전합니다.

✅ 발행 직전 체크리스트

  • 【빨간 글씨 자리】가 하나도 안 남아 있는지 (Ctrl+F로 「【」 검색)
  • 표가 스마트에디터에서 표 형태 그대로 붙여넣어졌는지
  • 사진 캡션과 출처 표기를 모두 채웠는지
  • 확정되지 않은 내용에 「예정 · 정부안」 같은 단서가 붙어 있는지
  • 제목 · 썸네일 문구 · 카테고리 · 발행 시간을 정했는지
  • 내용이 바뀔 수 있는 글이면, 재검토 일정을 캘린더에 잡았는지

🖼️ 이미지 원칙

  • 직접 촬영하거나 무료 저작권 이미지(픽사베이 · 언스플래시)를 사용
  • 뉴스 기사 캡처는 그대로 쓰지 말고 직접 표 · 그래픽으로 재구성
  • 출처 표기는 생략하지 않음
